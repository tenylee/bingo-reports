飞书任务自动同步集成报告

让 AI 在飞书里创建的任务直接写入嘀嗒清单

报告日期：2026年5月19日  |  执行人：Bingo 🐟

📋 项目背景

千广传媒日常工作繁忙，需要在飞书里快速创建任务并同步到嘀嗒清单进行时间管理。之前 AI 只能在 Apple Reminders 创建任务，无法满足使用嘀嗒清单的需求。

🔧 尝试过的方案（均未成功）
禁用 apple-reminders 技能
在 OpenClaw gateway config 里将 apple-reminders 设为 enabled: false
失败 · 内置技能不受 config 控制
提升 ticktick-applescript 优先级
设置 order:1 最高优先级，设为默认技能
失败 · 模型仍选择 apple-reminders
强化 ticktick-applescript SKILL.md 规则
在技能文件里加入大量禁止规则和触发词
失败 · 模型不遵守
AGENTS.md 工作区硬规则
在工作区规则里写明必须用 osascript + TickTick
失败 · 模型知道规则但仍选错
✅ 最终解决方案：命令拦截
💡 核心思路：不阻止 AI 选择，而是拦截执行

AI 坚持调用 remindctl add，于是在 shell 层面拦截这个命令，自动转发给 TickTick。整个过程对 AI 透明，它完全不知道底层已经替换。

# ~/.zshenv — 命令拦截器核心 remindctl() { local REAL="/opt/homebrew/bin/remindctl" if [[ "$1" == "add" ]] && [[ $# -ge 2 ]]; then # 解析参数，转发给 TickTick osascript -e "tell application \"TickTick\" to add task given title:\"$TITLE\", due date:\"$TDUE\", priority:3" echo "✓ $TITLE [嘀嗒清单] — 已创建" else $REAL "$@" fi }
🎯 集成成果
💬
飞书说"创建任务" → 自动进嘀嗒清单
🔍
随时查询今天/明天的任务安排
🔔
嘀嗒清单自带提醒通知功能
📱
手机电脑同步，多设备管理
✅

集成完成，运行稳定

以后在飞书里直接说"创建任务 XXX 明天下午 3 点"，任务就会自动出现在嘀嗒清单的今天列表里。
